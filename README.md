# БОбрезки — репозиторий обновлений

Публичный репозиторий с готовыми сборками программы **«БОбрезки»** — клиент и
сервер управления обрезками (раскрой, БАЗИС). Исходного кода здесь нет —
только релизы.

В релизе два архива:

| Файл | Что это |
|---|---|
| `BobrezkiClient_версия.zip` | Клиент (Рабочее место с БАЗИС-Раскрой,хранит список обрезков) |
| `BobrezkiServer_версия.zip` | Сервер (Главное место с БАЗИС-Раскрой,хранит список обрезков, раздаёт клиентам) |

## Установка

1. Скачайте нужный архив из последнего релиза.
2. Распакуйте в отдельную папку.
3. Запустите EXE-файл.

## Обновления

- Программа сама проверяет наличие новой версии **раз в 10 дней** (нужен интернет).
- Ручная проверка — кнопка «Проверить обновления» в меню программы.
- Найденное обновление скачивается, устанавливается, и программа перезапускается автоматически.

## Требования

- Windows 10 / 11
- Для связи клиента и сервера — локальная сеть или Radmin VPN
